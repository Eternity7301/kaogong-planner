# 考公计划书生成器

一个手机优先的网页应用：按你的**考试日期**和**每天可用的时间段**，自动倒排出一份精确到**每一天、每一个时段**的考公（国考/省考）计划书；每个时段的科目、时长、任务内容和题量都能自己改，支持打卡、统计、导出。

## 在线使用

打开 https://eternity7301.github.io/kaogong-planner/ ，在 iPhone Safari 里「分享 → 添加到主屏幕」，之后就像 App 一样从桌面图标打开，断网也能用（Service Worker 缓存）。

## 功能

- **分时段排课**：把每天设成几段（例如上午 08:30–10:30、下午 14:30–16:30），计划会把任务填进这些时段，段内自动留休息；工作日和周末可以分别设置，还能增删时段。
- **倒排到考试**：按剩余天数自动分阶段（基础夯实 → 强化突破 → 冲刺模考 → 考前一周），考前最后一天只做记忆回顾与模板默写。
- **具体到考点与题量**：内置行测五大模块 + 申论的考纲（约 50 个考点），按顺序推进，自动进入二轮复习。
- **按弱点分配时间**：每个模块自评「弱 / 中 / 强」，越弱分到的时间越多，也可用滑杆手动微调占比（自动归一化）。
- **完全可编辑**：点任意任务即可改科目、开始时间、时长、内容、目标题量；可「加时段 / 顺延时间 / 改目标 / 设为休息日 / 用本日分配套用到本阶段」。
- **打卡与统计**：完成率、累计时长、连续打卡天数、各模块时间分布。
- **数据在本机**：保存在浏览器 localStorage，不上传服务器；可导出 Markdown 计划书、导出/导入 JSON 备份、打印或存为 PDF。

## 说明

- 默认预置为「国考（行测+申论）」，考试日期是占位值（12 月第一个周日），官方公告发布后到「设置」里改成准确日期并重新生成即可。
- 修改后想自己部署：把本目录传到任意静态托管（GitHub Pages / Cloudflare Pages / 对象存储）即可，无需后端。
